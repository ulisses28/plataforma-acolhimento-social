Plataforma de Acolhimento Social
📌 Sobre o Projeto

A Plataforma de Acolhimento Social é um sistema web institucional desenvolvido como projeto acadêmico para apoiar organizações sociais sem fins lucrativos.

O projeto foi desenvolvido para atender às necessidades do Lar Batista Albertine Meador, instituição localizada em Serra/ES, dedicada ao acolhimento e apoio social de crianças, adolescentes e famílias em situação de vulnerabilidade.

A plataforma busca fortalecer a presença digital da instituição, ampliar a transparência institucional, facilitar doações e melhorar a comunicação com a comunidade.

🎯 Objetivos
Apresentar a instituição de forma moderna e profissional.
Divulgar projetos sociais e ações institucionais.
Facilitar o relacionamento com voluntários, parceiros e doadores.
Gerenciar doações financeiras e materiais.
Disponibilizar área pública de transparência.
Permitir publicação de notícias e comunicados.
Oferecer painel administrativo seguro.

🔐 Segurança

O sistema implementa:

Autenticação administrativa.
Criptografia de senhas utilizando bcrypt.
Tokens JWT.
Controle de sessão.
Logout seguro.
Política de senha forte.
Proteção de rotas administrativas.
Validação de CPF, CNPJ, telefone e e-mail.
Variáveis de ambiente para dados sensíveis.
