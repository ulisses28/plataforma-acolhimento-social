# MANUAL DO USUÁRIO

## Plataforma de Acolhimento Social

### Versão

1.0

### Instituição

Lar Batista Albertine Meador

### Objetivo

Este manual orienta administradores, colaboradores e usuários na utilização da Plataforma de Acolhimento Social.

---

# 1. Acesso ao Sistema

A plataforma pode ser acessada através do navegador web.

O sistema possui:

* Área Pública
* Área do Doador
* Área Administrativa

---

# 2. Área Pública

A área pública permite acesso às seguintes páginas:

* Home
* Quem Somos
* Projetos
* Transparência
* Governança Institucional
* Parceiros
* Notícias
* Seja um Voluntário
* Área de Doações

---

# 3. Realização de Doações

O sistema disponibiliza:

* Doação via PIX
* Doação via TED

O usuário poderá visualizar QR Code e dados bancários da instituição.

---

# 4. Área do Doador

A área do doador permite:

* Login
* Consulta de informações
* Alteração de senha
* Encerramento de sessão

---

# 5. Área Administrativa

A área administrativa possui acesso restrito.

Funcionalidades:

* Dashboard
* Cadastro de Parceiros
* Cadastro de Doadores
* Prestação de Contas
* Notícias
* Necessidades Institucionais
* Relatórios
* Governança Institucional

---

# 6. Gestão de Necessidades

O administrador poderá cadastrar:

* Alimentos
* Roupas
* Higiene
* Material Escolar
* Utensílios
* Outros

Cada necessidade poderá receber:

* Prioridade Alta
* Prioridade Média
* Prioridade Baixa

---

# 7. Publicação de Notícias

O administrador pode:

* Criar notícias
* Alterar notícias
* Excluir notícias
* Publicar comunicados

---

# 8. Segurança

Recomendações:

* Utilizar senhas fortes.
* Não compartilhar credenciais.
* Encerrar a sessão após utilização.
* Não utilizar computadores públicos.

---

# 9. Backup

O sistema permite exportação de backup administrativo.

Recomenda-se backup semanal.

---

# 10. Suporte

Dúvidas ou problemas devem ser reportados ao responsável técnico do sistema.
