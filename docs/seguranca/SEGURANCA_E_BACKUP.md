Segurança e Backup
Objetivo

Garantir a integridade, disponibilidade e confidencialidade dos dados da Plataforma de Acolhimento Social.

Segurança Implementada
Criptografia de Senhas

As senhas dos administradores são criptografadas utilizando:

bcryptjs

As senhas nunca são armazenadas em texto puro.

Autenticação

O sistema utiliza:

JWT (JSON Web Token)

para autenticação e autorização.

Controle de Sessão

O sistema possui:

Login administrativo.
Logout seguro.
Proteção de rotas.
Controle de sessão.
Validações

O sistema valida:

CPF
CNPJ
E-mail
Telefone
Proteção de Dados

Não são armazenados dados sensíveis de acolhidos.

A plataforma trabalha apenas com informações institucionais e de doadores autorizados.

Backup
Backup Manual

O administrador pode exportar os dados do sistema.

Backup Recomendado

Periodicidade:

Semanal

Local recomendado:

Google Drive
OneDrive
Armazenamento Institucional
Recomendações
Utilizar senhas fortes.
Não compartilhar credenciais.
Alterar senhas periodicamente.
Realizar backup antes de grandes alterações.
